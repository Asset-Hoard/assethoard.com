Features

Everything you need to organise, preview and find your game assets

Bring every pack in

Import from downloads, asset packs and project folders, and see every file before it lands in your library.

  • Visual importer: preview files, skip what you do not need and tag on the way in
  • Watched folders: new files in a folder you choose are picked up automatically
  • Archives: browse and preview inside zip, rar and tgz files without extracting them

Reads your engine’s files

AssetHoard reads engine formats directly, so you can browse, preview and tag them without opening the editor or installing a plugin.

  • Unity: inspect .unitypackage contents from any Unity version and drag assets into your project
  • Godot: previews for .tres materials, SpriteFrames, TileSets and fonts, dragged in with their dependencies
  • Unreal: reads .uasset and .umap packages and exports them with every dependency they reference
  • GameMaker: previews sprites, tilesets, sounds and fonts from .yy resources, .yymps packages and .yyz exports

See it before you open it

Thumbnails and live previews for sprites, 3D models, materials and audio, so you can judge an asset without opening another app.

  • 3D models: rotate glTF, FBX and OBJ models in an interactive viewport
  • Sprites: animated playback, plus spritesheet slicing into frames
  • Materials: preview .mtlx, .mat and PBR texture sets on a lit sphere
  • Audio: waveform thumbnails and inline playback with scrubbing

Find it in seconds

Search your library by meaning, tag or file type, and save the filters you use most.

  • Semantic search: find assets by meaning, not just filename, using local AI models
  • Tags and categories: colour-coded tags, auto-tags by file type and resolution
  • Smart filters: save the filters you reach for most
  • MCP server: search and copy assets from Claude Code, Cursor or VS Code

Keep it organised

Group assets by game or client, collapse alternates into a single tile, and track the licence on every pack.

  • Projects and bundles: organise by game, by client, or however suits you
  • Variants: collapse colour and resolution alternates into one tile
  • Licence tracking: licence files are detected on import, and you can set or override them per asset
