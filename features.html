Features

Everything you need to organize and manage your game assets

🗂️ Asset Organization

Structure your library exactly the way you want. AssetHoard gives you multiple ways to organize your assets:

  • Categories - Models, Textures, Sprites, Audio, VFX, and more
  • Custom Tags - Create colored tags for quick filtering
  • Bundles - Group related assets together
  • Nested Bundles - Organize complex projects with hierarchies
🖼️ Organization Screenshot 500 × 320

📥 Package Import

Import assets from your favorite sources without manually extracting files:

  • Unity Packages - Full .unitypackage support with metadata extraction
  • Godot Asset Packs - Import .zip files containing Godot projects
  • Folder Structure - Preserves original organization
  • Automatic Metadata - Extracts names, descriptions, and file info
🖼️ Import Screenshot 500 × 320

👁️ Visual Preview

See your assets without opening external editors. AssetHoard generates thumbnails for dozens of file formats:

  • Images - PNG, JPG, WebP, PSD, Krita, and more
  • 3D Models - glTF, GLB, OBJ with 3D rendering
  • Sprites - Aseprite files with frame/layer info
  • Audio - Waveform visualization for MP3, WAV, OGG, FLAC
🖼️ Preview Screenshot 500 × 320

⚡ Powerful Search

Find any asset instantly with AssetHoard's search capabilities:

  • Full-Text Search - Search names, descriptions, and metadata
  • Faceted Filters - Filter by category, tags, file type
  • Result Counts - See how many assets match each filter
  • Sort Options - By name, date added, file size

Undo/Redo

Made a mistake? Ctrl+Z works. Full undo/redo history for deletes, moves, and edits.

Backup & Restore

Export your entire library as a .assethoard file. Restore on any machine.

Keyboard Shortcuts

Power-user friendly with keyboard shortcuts for common actions.
🖱️

Drag & Drop

Import files by dropping them. Organize assets between bundles with drag and drop.
🌙

Dark Theme

Easy on the eyes during long creative sessions. No light mode—we're not monsters.
🔒

Local Storage

All data stored locally in SQLite. Your assets, your machine, your control.
