Asset Hoard v0.1.1 Release Notes

Linux has landed!

We've been hard at work bringing Asset Hoard to our Linux friends. This release includes ready-to-use Debian (.deb) and RPM packages. AUR support is still in progress — stay tuned!

🐧 Linux Support

Full Linux builds are now available:

  • Debian (.deb) — Ready for Ubuntu, Debian, and derivatives
  • RPM — Ready for Fedora, RHEL, and derivatives
  • AUR — Coming soon!

🐛 Bug Fixes

  • File path resolution — Resolved file paths incorrectly resolving on Linux
  • Audio playback — Fixed audio playback issues
  • File system permissions — Streamlined permissions with scoped access
  • Bundle search context — Fixed search context not resetting when navigating away from a bundle

✨ Improvements

  • Watched folders — Updated subfolder checkbox label to be more user-friendly

May your assets be organised and your bundles be nested.

Happy hoarding! 🐉
