Asset Hoard v0.1.10 release notes

Themes, import resume, and macOS signing

Asset Hoard now ships with a theme system and the ability to resume imports that were interrupted mid-flight. macOS builds are properly code-signed and notarised, and there is a solid round of settings polish and search improvements.

🔑 Preparing for Open Beta - Licensing

As AssetHoard is maturing we are starting to get the app ready for Open Beta. There's a transitional period before we start to require a license to continue using AssetHoard.

The license is a one-time purchase, which provides upgrades for life. While in Open Beta we'll have a small dismissable reminder that this is coming.

🎨 Theme Support

Nine built-in themes ship with this release. Pick one from Settings and your choice is saved automatically.

  • themes included — Classic, Midnight, Ember, Slate, Catppuccin, Nord, Rosé Pine, Tokyo Night, Catppuccin Latte

UI Improvements

  • Details panel toggle — show or hide the details panel with a keyboard shortcut; your preference is saved automatically
  • Sidebar tooltips — hover over sidebar items for quick context
  • Right-aligned project counts — project counts now sit neatly on the right side of the sidebar
  • Copy file path — a new button in asset details copies the full file path to your clipboard

📥 Importer Improvements

  • Auto-resume on restart — if the app exits during an import, you can choose to pick up where it left off next time you launch (see notifications in the app)
  • Faster material thumbnails — large speed improvements for Material thumbnails
  • AVIF support — Asset Hoard now recognises and previews .avif images

🔍 Search and filtering

  • Extension filter — search for *.png or any glob pattern to filter assets by file extension
  • Improved pagination — search results now paginate more reliably with better near-bottom scroll detection

🍎 macOS code signing

  • Signed and notarised builds — macOS releases are now properly code-signed with entitlements and notarised via the Apple notary service

🛠 More improvements

  • UNC and network path support — drag-and-drop now works with Windows SMB and NAS paths
  • Keyboard shortcut for settings — jump straight into settings without touching the mouse

May your assets be organised and your themes be aesthetic.

Happy hoarding.
