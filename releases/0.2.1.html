v0.2.1 September 11, 2026

Unreal Engine asset support

AssetHoard is a local-first asset manager for game developers and digital artists. This release adds support for Unreal Engine assets, builds materials from PBR texture maps, and adds more ways to export assets from your library.

🎮 Unreal Engine asset support

Import an Unreal project's .uasset and .umap files and preview them without opening the editor.

  • StaticMesh and SkeletalMesh preview as an interactive 3D orbit.
  • PaperSprite and PaperFlipbook animate from their referenced frames, and SoundWave and SoundCue play back as auditionable sound sets. Anything else falls back to the baked editor thumbnail.

  • Imported packages resolve their /Game/ references and surface them in the References panel, and a material's textures show as thumbnails in Associated files.

🎨 Materials from PBR textures

Combine albedo, normal, roughness and metallic maps into a single material you can preview and export.

  • Select the maps and combine them into one card with a live preview sphere and a per-channel fan-out.
  • Edit the channel mapping in the detail panel, watching the preview sphere update as you go, with a full expanded preview that includes lighting and channel selection.
  • Export the material as MaterialX (.mtlx), or as all of its member maps, not just the albedo.

📤 More export options

  • Right-click a package and export its whole reference tree to a folder in one go.
  • Save a 3D model's preview as a transparent PNG.
  • Pack a spritesheet from any multi-selection of images, or from a variant group whose members are all sheetable.
  • Split a texture into per-channel greyscale PNGs.

📦 New formats in the library

  • FreeCAD (.FCStd) files import with a thumbnail and metadata.
  • Pixelorama (.pxo) files import with a preview, a layer list, export, and their own type badge.
  • Godot AudioStreamRandomizer and AudioStreamPlaylist (.tres) files preview as auditionable sound sets.

🧭 Navigation and filtering

  • An "up" button in the toolbar moves back up a nested bundle hierarchy.
  • Type and Ecosystem facets now filter bundles as well, by their contents, not just the loose assets.
  • The "Recently added" component is nwo on the Library sidebar and is static until you hover, then plays its animated tiles, so the sidebar no longer flickers.
  • The spritesheet editor has a "Slice Sprite Sheet" action in the right-click menu.

🚀 Onboarding and imports

  • An empty library shows live import progress instead of a blank screen.
  • Imports show an estimated time remaining as they run.

🐛 Settings and polish

  • The About page has been redesigned around a hero, in-app updates, What's New, and links to our socials.
  • The Classic theme is now a flat graphite.
  • Tooltips moved onto one shared implementation, and the "arrow keys preview audio" hint no longer shows when it isn't relevant.

🛠 Under the hood

  • Inputs, textareas, buttons, form groups and pickers across settings, bundles, imports, projects and bulk edit now use the same shared components, for consistent behaviour across the app.

Happy hoarding.
