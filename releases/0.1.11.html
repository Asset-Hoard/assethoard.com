AssetHoard v0.1.11 release notes

Smarter search, safer imports, smoother audio

This release sharpens semantic search with real filter support, makes the importer safer when several imports are running at once, and introduces crisper waverforms. There is also a solid performance pass across bundle loading asset reloads.

🔍 Search and discovery

We've promoted Search from experiments to a standard feature, and are continuing to add improvements along the way.

  • Semantic search filters: filters now apply to semantic queries, so you can combine natural-language search with the same filters you already use for keyword search
  • Search settings section: a new Search area in Settings makes semantic search easy to configure and manage
  • Case-insensitive tags: tags now match regardless of case, and a one-off migration merges any existing duplicates so your library stays tidy
  • Sort by duration: sort audio and video assets by length, with cleaner duration and file-size formatting in the grid
  • Stable sort order: columns that cannot be sorted directly now fall back to sorting by name, keeping the order predictable

📥 Import pipeline

A series of improvements and bug fixes have made for the import system. Still lots more to do!

  • Concurrent import tracking: each import is assigned its own ID, so notifications stay accurate when several imports are running side by side
  • 🐛 Packages now import into the correct folder: unitypackages were being improted without a bundle (even when they were supposed to be) - this has been fixed
  • 🐛 Package bundle polish: the "Create sub-bundle" option is now hidden on package bundles where it does not apply
  • Improved Cover Image Setting speeds up processing over setting cover images at time of import
  • Improved thumbnail generation around 300% increase in speed, and added more stability
  • Leaner memory footprint: reduced the memory footprint requirements of semantic search indexing

🔊 Audio

Improved the display and future capability of the waveforms. For now, it's improved visuals, but it unlocks drag and export, theme support, and more.

  • Waveforms: waveform thumbnails are now rendering dynmically instead of thumbnailed, resulting in crisper rendering
  • Minimum duration display: very short audio assets now show their actual length instead of rendering as 0:00

⚡ Performance

  • Batched bundle loading: bundles and their assets load in batches, cutting database round-trips (~15% increase in speed)
  • Atomic asset reload: bulk operations now reload via a merge, so there is no flash of stale data afterwards
  • Faster image thumbnails: a quicker downscaling algorithm speeds up thumbnail generation (benchmarked at ~300% increase in speed)
  • Smoother drag hovers: hover updates during drag operations are smoother and less cpu intensive (slight improvement in speed and responsiveness)

✨ Bundles and UI polish

  • Inline bundle rename: rename bundles directly in the sidebar
  • Selection hygiene: navigating into a bundle now clears any stale main-grid selection, so bulk actions always target what you expect
  • DB Maintenance: soft-deleted records are cleaned up in the background once a day, and a toast reports how much space has been reclaimed
  • DB corrupted screen: If the AssetHoard DB is corrupted (power outage, etc.) then a popup is displayed on boot giving the user the option to restore from an automatic backup

🐧 Platform

  • Wayland rendering fix: Wayland with Nvidia could stop the Assethoard from running, a small fix to attempt to work around this

🛠 Under the hood

Since we're all devs, some behind the scenes stuff.

  • A broad dependency refresh across all the dependencies used by AssetHoard are now 100% up to date

May your waveforms be crisp and your imports be orderly.

Happy hoarding.
