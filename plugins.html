Our plugin promises

Powerful plugins shouldn't cost you your trust

Plugins are code from outside AssetHoard running next to your library. So we built the system around six promises, and the app enforces every one of them.

  1. 01

    Your library stays yours

    Plugins run on your computer, inside AssetHoard. They don't phone home, and your files never leave your machine.

  2. 02

    Sandboxed by default

    A plugin can't touch your files, the network or other programs. It sees the one file it's asked to read, and nothing else.

  3. 03

    Nothing hidden

    Before you install, you see every file type a plugin reads, every file it puts outside AssetHoard and every permission it wants. If an update asks for more, you are asked again.

  4. 04

    Add, never override

    Built-in formats always come first. A plugin can teach AssetHoard something new, but it can't change how your PNGs, models or audio are read.

  5. 05

    Reviewed and signed

    Nothing reaches the registry without review, and a change to permissions needs a second approval. Every download is signed and checked before it installs.

  6. 06

    You stay in control

    Updates are never automatic. Switch a plugin off any time. If one hangs or crashes, it's stopped and AssetHoard carries on.

Why plugins

Fill the gaps, keep the app lean

Every project has a few files AssetHoard doesn't read yet: phone photos, engine-specific formats, the output of a niche tool. A plugin fills one gap without waiting for an app update, and you only install the ones you need.

File format plugins

Add extensions AssetHoard can't read, so those files get thumbnails, previews, details and Export As like everything else in your library.

Integration plugins

Connect AssetHoard to another tool. Browse and import your library from inside the Godot editor, without switching windows.

Getting started

Three clicks to a new format

  1. 1

    Browse

    Open Settings > Plugins in AssetHoard and go to Browse.

  2. 2

    Review

    Pick a plugin and check what it reads, installs and asks for.

  3. 3

    Install

    Click Install. It works straight away, no restart.

Updating, switching off and troubleshooting are covered in the plugins docs.
