About the 3D model inspector

Before you drop a downloaded or purchased model into a project, it helps to know its polygon count and how it is built. This inspector reads OBJ, glTF and GLB files and reports their key stats so you can judge whether a model is a good fit without opening a full 3D editor.

How to use the 3D model inspector

  1. Drop an OBJ, glTF or GLB file.
  2. Read the vertex and triangle counts.
  3. Check the number of meshes, materials and textures.
  4. Note the bounding size to see the model scale.
