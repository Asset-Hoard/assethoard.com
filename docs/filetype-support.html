Textures & Sprites

FormatExtensionsThumbnail
Standard images.png .jpg .jpeg .webp .bmp .icoYes Lanczos3 resize
Targa.tga .targaYes
SVG.svg .svgzYes
Photoshop.psdYes flattened composite
Krita.kraYes merged layer
Aseprite.ase .asepriteYes first frame, nearest-neighbor
Spine.skel .atlasYes atlas page image
GIF.gifYes first frame
Other.dds .exr .hdr .tiff .tifNo

Preview: Standard image viewer for raster formats. Aseprite and GIF files get frame-by-frame animation playback with timeline scrubbing. Aseprite files also show a layer panel.

Spine: exports from Spine 3.6 to 4.3 (libGDX atlases too). The details panel shows the Spine version, skeleton size, pages and regions, and a skeleton lists its atlas and page images under Associated files. Previews are static, so you see the packed body parts rather than an animated character.

3D Models

FormatExtensionsThumbnail
GLTF / GLB.gltf .glbYes rendered on import
Wavefront OBJ.objYes rendered on import
FBX.fbxYes rendered on import
LightWave.lwoYes LWO2 and LWO3, not legacy LWOB
Blender.blendYes embedded thumbnail if present
FreeCAD.FCStdYes embedded thumbnail, no interactive preview
Other.dae .3ds .stl .abcNo

LightWave: LWO3 files load their textures, and the details panel lists each surface's images, flagging any that are missing. LWO2 files preview with surface colours, without textures yet. Re-save LWOB files (LightWave 5 and earlier) from LightWave 6 or later, or convert them to glTF.

See the 3D Files documentation for details on texture loading and file structure.

Packages

FormatExtensionsDescription
Unity Package.unitypackageScans and imports Unity Asset Store packages. Extracts embedded preview thumbnails. Auto-creates a bundle per package. See the Unity Packages documentation for details.
Unreal Package.uasset .umapReads Unreal Engine packages directly, with no editor or plugin. Classifies each package, previews meshes, sprites and audio, and maps their dependencies. See the Unreal Packages documentation for details.
GameMaker Package.yymps .yyzReads GameMaker local packages and project exports without unpacking them. Sprites, tilesets, objects, sounds and fonts inside are indexed and previewed like loose files. See the GameMaker files documentation for details.
Godot Project or Addon.zipA zip containing a project.godot or an addons/*/plugin.cfg is badged as a Godot package, with its name, Godot version, author and description. Loose .tres resources are previewed with their references. See the Godot resources documentation for details.

Archives

FormatExtensionsDescription
Zip.zipReads inside the archive on import and indexes the files and folders within. Browse the contents as if they were on disk, and click any file for a live preview without extracting it. See the Archives documentation for details.
RAR.rar
Gzipped tar.tgz .tar.gz

Preview: Files inside an archive preview the same way they would as loose files, loaded on demand one at a time. You can drag the whole archive out, but not individual files from inside it.

Other Files

Any unrecognised file can still be added to your library. It gets basic file info (size, timestamps, MIME type) and a generic icon. You won't get thumbnails or previews, but the file is fully searchable and taggable like any other asset.
