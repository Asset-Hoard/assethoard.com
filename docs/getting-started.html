Getting Started

Get up and running with AssetHoard in just a few minutes

Download and Install

Download the installer for your platform and run it. AssetHoard will be installed and ready to use in seconds.

Create Bundles

Bundles let you group related assets together. Create a bundle for each project, asset pack, or however you like to organize. Bundles can be nested for complex hierarchies.

Import Your First Assets

There are several ways to add assets to your library:

  • Drag and drop files or folders directly into the app
  • Use File → Import Assets from the menu
  • Import .unitypackage or Godot .zip files

Organize with Categories and Tags

Select any asset and use the sidebar to assign a category (Models, Textures, Audio, etc.) or add custom tags. Tags can be color-coded for quick visual identification.

Search and Filter

Use the search bar to find assets by name or description. Click the filter icon to narrow down by category, tags, or file type. The faceted search shows you exactly how many assets match each filter.
