Keyboard Shortcuts

Speed up your workflow with these keyboard shortcuts

On macOS, Ctrl is replaced by Cmd for most shortcuts.

Navigation

ShortcutAction
← → ↑ ↓Navigate between items
EnterOpen selected bundle
BackspaceGo back to parent bundle

Selection

ShortcutAction
Ctrl+ASelect all visible items
EscapeClear selection / blur focused input

Actions

ShortcutAction
DeleteRemove selected items
F2Rename selected bundle (or current bundle if none selected)
Ctrl+IImport files
Ctrl+,Open settings
Ctrl+ZUndo
Ctrl+Shift+ZRedo

View

ShortcutAction
GSwitch to grid view
LSwitch to list view
Ctrl++Larger cards (fewer columns)
Ctrl+-Smaller cards (more columns)
\Focus search input
?Show keyboard shortcuts help
