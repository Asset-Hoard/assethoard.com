Your game engine reads these files. Your file browser doesn't.

To Explorer and Finder, your Unity packages, Godot resources and zipped asset packs are just blank icons. So you rebuy the pack you already own.

AssetHoard is a local-first desktop asset manager for game developers. It reads engine-native formats, including Unity .unitypackage, Godot .tres, Unreal .uasset and GameMaker .yymps, alongside 80+ file formats such as .aseprite, .krita, .fbx, .gltf, .blend, .wav, .ogg, .png and .jpg, and previews what's inside .zip archives without extracting them. It runs on Windows 10+, macOS 11+ and Linux, stores all data on your machine with no cloud dependency, and handles libraries of 800,000+ files. It is a one-time purchase with no subscription fee.

Bring every pack in

Visual importer + watched folders

Preview files before importing. Filter and ignore what you do not need, apply tags on the way in, and let smart license parsing detect CC0, MIT, and more.

Peek inside archives

Browse and preview the files inside zip, rar, and tgz archives as if they were already extracted. No unzipping just to see what you have.

Materials support

Find it in seconds

Semantic search

Find assets by meaning, not just filename. Search for 'water' and get results even if the file is called IMG_4392.png.

Tags and categories

Projects and bundles

License tracking

Track CC0, attribution, or commercial licenses on every asset and pack.
