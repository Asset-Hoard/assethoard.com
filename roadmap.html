Roadmap

What we're building and where we're headed

This is a living document. Priorities shift based on feedback and what we learn along the way. Don't see something you need? Let us know.

Now

Currently in progress

  • Improve Large Imports

    Large imports of over >5000 assets can cause some freezes. We will optimise the import process to make this more performant

  • Improve Watched Folder capability

    When adding a watched folder you'll be given an option to add tags, categories, or licenses to all imported items

  • Improve project/bundle asset adding

    Currently we can only drop assets and bundles into the sidebar, or bundle cards. This will support dragging into the main view of empty bundles or packages.

Next

Up next on our list

  • Folder watching improvements

    Better handling of large directories and network drives.

  • Improve Unity Package handling

    Improve the capability of unity asset management by introducing renaming, open directory, and open asset store

  • Improve import functionality

    Allow bulk import functionality to automatically add tags, categories and licenses to all imported items

Later

On the horizon

  • Blender support

    Allow blender 3d files to be added directly to asset hoard, supporting animations, models, and materials

  • Community asset packs

    Discover and share curated asset collections.

  • Custom metadata fields

    Define your own fields beyond tags and categories.
