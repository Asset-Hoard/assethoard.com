Roadmap

What we're building and where we're headed

This is a living document. Priorities shift based on feedback and what we learn along the way. Don't see something you need? Let us know.

Now

Currently in progress

  • Folder watching improvements

    Enable watching of an imported folder for changes

  • Workbench

    Temporary pin/hold assets while you find the perfect one

  • Smart Collections

    Using search, and other context, save a collection of assets for later retrieval

Next

Up next on our list

  • Custom metadata fields

    Define your own fields beyond tags and categories.

  • Search by colour

    show colour pebbles, and allow filtering and searching

  • Plugin Support

    Additional Filetypes, third party library support, and context menu items

Later

On the horizon

  • Community asset packs

    Discover and share curated asset collections.

  • Ollama plugin support

    Connect Ollama to provide text descriptions of images, and smart tags
