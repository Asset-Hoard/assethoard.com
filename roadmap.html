Roadmap

What we're building and where we're headed

This is a living document. Priorities shift based on feedback and what we learn along the way. Don't see something you need? Let us know.

Now

Currently in progress

  • Improved 3D management

    Better texture and material management

  • Improved 3D preview performance

    Faster loading and smoother interaction for complex models.

  • Improved search

    Powerful search utilising all meta data in your library including dates, tags, and categories

  • Batch rename tools

    Rename multiple assets at once with pattern matching.

Next

Up next on our list

  • Collection sharing

    Export and import collections to share with teammates.

  • Cloud backup option

    Optional encrypted backup of your library metadata to the cloud.

  • Folder watching improvements

    Better handling of large directories and network drives.

  • Previews for major formats

    Rich previews for major asset formats including 3D models, 2D images, audio files, and textures.

Later

On the horizon

  • Plugin system

    Build and share extensions for custom workflows.

  • Community asset packs

    Discover and share curated asset collections.

  • Blender file support

    Native .blend file parsing for previews and metadata extraction.

  • Custom metadata fields

    Define your own fields beyond tags and categories.
